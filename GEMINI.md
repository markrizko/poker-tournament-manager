# Collaborative Preferences & Guidelines

- **Explain Before Acting**: Whenever asked to perform a task, and especially when asked for opinions, architectural advice, or suggestions, always explain your reasoning, evaluation of options, and step-by-step plan FIRST before creating/editing files or running terminal commands.
- **Collaborative Dialogue**: Discuss tradeoffs and verify approach with the user rather than jumping straight into code changes unannounced.
- **Seek Confirmation When Uncertain**: If multiple architectural or design approaches exist, present them clearly and confirm user preference before executing.
